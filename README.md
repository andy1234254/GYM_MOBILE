# GymMobile
This project was developed with .NET MAUI 10, using C# for the underlying code, models, and services, and XAML for the views. It focuses on the organization and administration of a gym (Android and Spanish only), including member registration with photos, credentials, and daily attendance tracking; product registration; income and expenses tracking; a product store; and monthly closing. It supports both offline and online use, utilizing SQLite for local storage and Firestore and Firestorage for remote storage. To test this program, please implement your own Firebase credentials or configurations, as well as any other external configurations (depending on your computer).
